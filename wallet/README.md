# Apple Wallet Business Card

This folder contains the source configuration for Sayed Ahmed AlMosawi's Apple Wallet business card.

- Pass Type ID: `pass.Sayed.AlMosawiDigital.Business.Card`
- Team ID: `GJ4AP2CYA7`
- QR destination: `https://ialmosawi.github.io/Sayed-AlMosawi-Digital-Card/`

The private key and exported P12 certificate must never be committed to this repository. Final signing is performed locally on the Mac where the Pass Type ID private key is stored.

The production artwork files (icon, logo and portrait thumbnail) are included in the downloadable Wallet source package supplied separately and can be copied into this folder before signing.
